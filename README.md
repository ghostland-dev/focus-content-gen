# Focus Content Generator

[![CI](https://github.com/ghostland-dev/focus-content-gen/actions/workflows/ci.yml/badge.svg)](https://github.com/ghostland-dev/focus-content-gen/actions/workflows/ci.yml)

Markdown content generator with live preview.

## Features

- Markdown rendering (GFM)
- SEO metadata

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/focus-content-gen.git
cd focus-content-gen
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
